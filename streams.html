First-time seller setup
Create your key, then connect OBS

Create your private connection on Crack Packs first. Sellers do not need a Cloudflare login or Cloudflare API token.

  1. Click Create Key once and leave this page open while Crack Packs requests a private live input.
  2. Wait for OBS key created and displayed. The RTMPS server and Stream key fields will appear on this page.
  3. Copy both values and keep the Stream key private. Use Save if you also want a local backup of the key.
  4. Open OBS and go to Settings > Stream.
  5. Set Service to Custom.
  6. Paste the RTMPS server into OBS Server and the Stream key into OBS Stream Key.
  7. Save OBS. Future shows reuse this connection until you intentionally choose Regenerate Key.
  8. Start streaming in OBS before opening auctions on Crack Packs.

After your first successful key creation, this guide stays tucked away unless you open it with the OBS setup guide button.

If the RTMPS server and key do not appear, stop before changing OBS and contact Crack Packs support. A site administrator must repair the Cloudflare Stream service or platform token; sellers should never create or submit that token.
